# Getting started with ModBee OpenPLC

New to OpenPLC or to the ModBee Node UIO? Start here. These pages take you
from installing the editor to a Ladder program running on the board, one step
at a time, with a screenshot for each step.

1. [Overview](01-overview.md): the Node UIO, the editor, the board package and
   the libraries, and why ModBee boards use the ModBee OpenPLC Editor.
2. [Install](02-install.md): the editor, the board package and the libraries,
   all at once from one ZIP or one at a time.
3. [First project](03-first-project.md): choose the Node UIO, switch on its
   library, and understand PLC tasks.
4. [First Ladder program](04-first-ladder.md): inputs, a lamp, a timed pump;
   compile, upload and watch it live.
5. [Next steps](05-next-steps.md): the libraries' own documentation, the
   hardware, and the OpenPLC documentation.

The screenshots are from the ModBee OpenPLC Editor on Linux. On Windows and
macOS the screens are the same, apart from the window frame.
